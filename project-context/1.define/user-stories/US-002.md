### 1. Story Identity

- **ID**: US-002
- **Title**: Resolve a missing role
- **Priority**: Must
- **Persona**: HR coordinator

### 2. Narrative

As an HR coordinator, I want clarification from the manager so the system uses an authorized role.

### 3. Acceptance Criteria

1. Given a blank role, when the record is received, then one request is sent to the designated manager and no tasks are created.
2. Given a reply such as “We hired a CSR” from the designated manager, when that reply is applied, then the approved plan is produced and awaits HR activation.
3. Given an ambiguous reply, when it is received, then one targeted follow-up is sent. Given another insufficient reply or an elapsed deadline, when that occurs, then the case escalates.
4. Given a reply from another participant, when it is received, then it cannot establish the role or approve the plan.

### 4. Scope Notes

- **In Scope for MVP**: Jordan’s missing-role intake; one targeted follow-up per clarification round; simulated manager and HR replies; escalation on a second insufficient reply or on silence at the request deadline.
- **Deferred**: Live communication channels. Automatic replanning after a role or location change is outside this MVP; that change requires HR review.
