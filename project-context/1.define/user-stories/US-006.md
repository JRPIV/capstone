- **Title**: Review readiness and decisions
- **Priority**: Must
- **Persona**: HR coordinator

### 2. Narrative

As an HR coordinator, I want a reliable summary so I can act on the remaining issues.

### 3. Acceptance Criteria

1. Given a hire plan, when HR opens the summary, then the summary implements BR-6 and links each confirmed arrangement to supporting evidence.
2. Given a held plan or an escalation, when HR acts, then HR can approve the held plan and record an escalation disposition with identity, timestamp, rationale, and version.
3. Given an exception decision, when it is recorded, then it does not mark an incomplete task complete or remove its unresolved status.
4. Given a change that affects a recorded decision, when it is applied, then the decision is identified as requiring review and the previous decision is preserved.

### 4. Scope Notes

- **In Scope for MVP**: Readiness labels Ready and Needs attention; execution status separate from readiness; overdue and escalated indicators; recorded HR decisions; evidence open from the task.
- **Deferred**: Richer reporting. Layout may be refined later without changing the authority or readiness rules.
