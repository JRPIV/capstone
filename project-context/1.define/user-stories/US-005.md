- **Priority**: Must

### 2. Narrative

As a new hire, I want an answer I can verify against approved company policy.

### 3. Acceptance Criteria

1. Given a paraphrased question covered by P1–P4, when it is asked, then the answer cites the relevant passage and preserves its meaning.
2. Given a loaner-policy question, when it is answered, then the answer explains eligibility and does not claim that equipment has been arranged.
3. Given a question about remote work, pay, overtime, or eligibility, when it is asked, then it is marked outside the pack and routed to HR, with no invented answer.
4. Given a model or retrieval failure, when the question is handled, then the visible state is retry or manual review and no policy conclusion is created.

### 4. Scope Notes

- **In Scope for MVP**: The fictional P1–P4 pack; paraphrased questions; one remote-work question routed to HR; a visible failure when retrieval fails.
- **Deferred**: A larger policy pack, pay or eligibility guidance, and production knowledge bases are out of this release.
