### 1. Story Identity

- **ID**: US-004
- **Title**: Replan after a start-date change
- **Priority**: Must
- **Persona**: HR coordinator

### 2. Narrative

As an HR coordinator, I want only affected work updated so the plan remains accurate.

### 3. Acceptance Criteria

1. Given a start-date change, when the plan is updated, then completed tasks remain complete and unfinished dates match Appendix A’s offsets.
2. Given a meeting scheduled for the previous start date, when the start date changes, then that meeting becomes unconfirmed and a reconfirmation request is generated.
3. Given an equipment commitment, its ready date, and the new start date, when the change is applied, then equipment is re-evaluated using BR-4 and BR-5.
4. Given a prior plan version, when the change is applied, then that version remains available. Given a duplicated change event, when it is processed, then the request is not repeated.

### 4. Scope Notes

- **In Scope for MVP**: Later starts in D7 and the earlier start in D8; Austin business days with no holiday calendar; overdue flags for missed deadlines; preservation of prior plans and decisions.
- **Deferred**: Holiday calendars. Automatic replanning of a role or location change is outside this MVP.
